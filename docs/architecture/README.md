# BankCore Architecture Foundation

This folder defines the architectural baseline for BankCore.

- clean-architecture.md: layer boundaries and dependency rules
- ddd.md: bounded contexts, aggregates, and ubiquitous language guidance
- cqrs.md: command/query separation and read model strategy
- outbox.md: reliable event publication with transaction consistency
- saga.md: distributed transaction orchestration/choreography strategy
- strategy.md: runtime policy/algorithm composition pattern
